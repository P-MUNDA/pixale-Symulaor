# Lesson 1

- Always check your canvas import. Make sure it is exactly the canvas class/id you specified in your HTML file.
  - *Note: I wasted 3 hours reading, doubting, and crying just because I copied the HTML code from my other project and forgot to change the canvas name.*

- If you are using `context.rect(0, 0, w, h)`, don't forget to fill it with `context.fill()`.

- Alternatively, you can use `context.fillRect(0, 0, w, h)`;
